# 波斯波利斯完整案例

本案例主体选取约公元前 430 年的王室宫殿群，同时保留一幅有明确推定边界的区域全景。约定年代不意味着每个附属区块、屋顶或外围聚落都已证实处于同一状态。

- 9 项来源，23 条标准化主张（20 条主体主张及 3 条区域主张）。
- 核心 1883 个、区域 2530 个实际网格对象；核心柱网按记录检查。
- 11 幅结果，16 次实际生成/修改阶段；最终、原生、弃用图和提示词保留。
- 8 项过程经验；其中 4 项具有生成前后对照图。

`case.json` 是开源版的标准入口；`recorded/` 是原制作资料；`IMPORT_MANIFEST.json` 逐项说明保留与未打包文件。原制作记录与新技术验收不混用。

`model_recipe.py` / `context_recipe.py` 是本版可运行配方。`legacy-process/` 保留原始研究、建模、提示词、生成后处理、展馆与打包脚本，少量本机路径经过显式脱敏。原流程的生图调用发生于客户端工具中，并不存在一份可凭空重放该远程服务的 Python 程序。

## 应继续审查的限制

当前 PP04 的编辑有真实记录，但原来“人头改牛头”的诊断缺乏保留图像支持，已经公开勘误；两版都有牛头特征，身体姿态和雕刻细部仍有生成失真。PP05 等场景的图像可见柱数、所有画面与模型的严格吻合，尚未独立认证。完整屋顶、色彩、地形、住宅密度与 Firuzi 在 430 BCE 的使用状态仍有推定。不要将生成图用于精确测绘、人口计算或原始雕塑复原。

见 case.json/failures 的观察、操作、经验、状态和证据路径；运行生成的展馆会展示前后图及这些限制，而不只展示“修好了”的结果。

从项目根目录按 README 运行。这个目录内没有第三方考古底图；其来源与 SHA 保存在 external_assets。完整论文下载失败和原研究的读取范围也如实保留。
