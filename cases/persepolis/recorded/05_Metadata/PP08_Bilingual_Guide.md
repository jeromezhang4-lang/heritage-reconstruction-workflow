# PP08 百柱厅 · 深处的秩序

百柱厅内部以更密集的柱阵展开长距离视线。宽大的地面与有顶空间共同表现其秩序，少量远处人物让柱间距和屋顶高度更容易感知。

参考模型包含100根主厅柱，但一个透视画面无法同时看清全部柱子。完整梁架与墙面仍是复原方案，人物不被认定为某位国王或某次真实朝会。

## Within the Hundred Column Hall

Long diagonals through a dense column grid reveal the scale of the roofed Hundred Column Hall. A few distant figures clarify spacing and height.

The mesh contains one hundred main columns, but no single perspective reveals them all. Roof framing, surfaces and activity remain hypotheses.

证据项目：T08, T09, T17, T19。
