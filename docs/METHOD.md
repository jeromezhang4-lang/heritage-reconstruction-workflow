# 方法与既有工作

项目采用“历史依据优先，其次空间一致性，再考虑画面质量”的制作次序。先记录已知、推定和未知，再建模与生成；参考图不能替代对输出本身的检查。

公开数据关系是：source → claim → component / scene → camera → actual generation records → review → release。v0.1.0 用相对路径与显式编号连接现有案例，运行时校验关键关系与文件，不声称已实现完整的知识图谱或自动事实核验。

《伦敦宪章》与《塞维利亚原则》已有来源、过程、透明性及可审查性的要求。本项目是在 AI 图像制作中实践这些方向，不声称获得相关机构认证或全面符合性审计。

- London Charter: https://londoncharter.org/
- Seville Principles, especially scientific transparency: https://icomos.es/wp-content/uploads/2020/06/Seville-Principles-IN-ES-FR.pdf
- 3DHOP, interactive heritage model presentation: https://www.3dhop.net/
- ATON, collaborative heritage Web3D/WebXR: https://github.com/phoenixbf/aton

可用证据是局部的：本项目的 QA 证明某些结构与程序行为，不证明历史命题必然成立。建议研究者在来源、组件、生成图和解释之间继续审阅与纠错。
