# 材料许可与公开边界

本版区分代码、第一方案例内容与第三方研究资料。

- 第一方代码、技能指令和工具：MIT，见 LICENSE。
- 第一方研究说明、手工近似数字化的案例数据、参考渲染与生成图：在许可人持有的权利范围内 CC BY 4.0，见 LICENSE-CONTENT.md。AI 输出是否具备著作权及其他权利取决于适用规则；本项目不制造不存在的排他权，也不替第三方授权。
- 第三方考古总平面和区域地图：不包含其位图。`case.json/external_assets` 记录原路径、哈希、来源 ID 与未打包原因。完整网页和书籍也不打包。原生图与提示词仍保留实际制作记录，不能据此推断其中涉及的第三方材料已获重新分发授权。
- 第三方依赖和权重：依赖通过其各自官方分发安装，保留原许可；不附带 FSRCNN 模型权重。案例记录包含来源与原权重哈希。

原始制作包的 `SOURCE_AND_RIGHTS.md` 是历史研究记录；其中的研究性引用不构成将所有图版放进一个宽松许可仓库的授权。本版更保守地移除四张外部图及重复归档图，只保留出处和可验证的记录。

需要外部图版时，请从 case.json 所列的机构/出版者页面取得，并自行遵守其条件。它们不是离线重建展馆、模型和修正案例的必要输入。重新开展史料研究时仍应查看原图，不能把本项目的近似模型当作原始测绘。

公开版本不含账号、cookies、API key、原始聊天、个人目录或本地服务地址。历史执行脚本中的作者本机路径被替换为明确占位符，修改情况和原文件哈希记录在 legacy-process/MIGRATION.json；这些脚本作为过程证据保留，不是当前运行入口。
