# Contributing

Corrections to evidence, chronology, geometry and documentation are welcome. Cite the exact source/figure and distinguish its statement from your interpretation. Preserve unknowns, old image attempts and meaningful decision history.

For a new case, use `init`, replace placeholders, freeze deliberate inputs and include a reproducible documented route. Do not put unlicensed research images, credentials, personal paths or raw private conversations in a contribution.

For code changes, run the unit tests and the README replay in a new output directory. Explain the concrete behavior changed. New historical assertions need historical review; passing a program test is not evidence that the assertion is true.

Please report uncertainty and defects directly. The project does not assign a numerical archaeological accuracy score and does not advertise independent certification without an actual expert review record.
